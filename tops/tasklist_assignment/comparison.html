Procedural C vs OOP C++ TaskList

The C version uses global arrays and separate functions, while the C++ version groups task data and behavior into classes and methods.

Three Problems in the C Version Solved by OOP

  1. Global data management: In C, the task array and task count are global variables, so many functions can access and modify them directly. In C++, the TaskList class keeps the task collection private and controls access through methods such as addTask() and markTaskDone().
  2. Limited data structure: The C version has a fixed-size array that can hold only five tasks. The C++ version uses vector<Task>, which can grow dynamically as tasks are added.
  3. Data and behavior are separated: In C, task information and functions that operate on it are separate. In C++, the Task class combines the task's data (title and isDone) with behavior (markDone() and display()). This makes the program easier to organize and extend.

Summary

The procedural C approach works well for a small fixed task list. The OOP approach provides better organization, encapsulation, and flexibility as the program becomes larger.
