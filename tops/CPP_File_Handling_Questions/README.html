C++ File Handling Assignment

This ZIP contains separate files for all five questions.

Files

  • Q1_Create_Favorite_Songs.cpp - Creates my_fav_songs.txt and writes 5 songs using ofstream.
  • Q2_Read_Favorite_Songs.cpp - Reads my_fav_songs.txt using ifstream.
  • Q3_Append_New_Song.cpp - Appends a user-entered song using ios::app.
  • Q4_Flipkart_Wishlist_Tracker.cpp - Saves 3 products and prices to wishlist.txt, then reads and displays them.
  • Q5_Count_Instagram_Followers.cpp - Counts usernames in insta_followers.txt without using an array or vector.
  • my_fav_songs.txt - Sample input file for Questions 1-3.
  • insta_followers.txt - Sample input file for Question 5.

No JavaScript files are included.
